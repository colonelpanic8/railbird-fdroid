Railbird F-Droid Repository

This is Railbird's official direct Android distribution channel. It serves the same signed, architecture-specific APKs attached to Railbird's Gitea releases, with automatic updates through an F-Droid-compatible client.

Add this repository to F-Droid

If the button does not open your client, add this address manually:

https://colonelpanic8.github.io/railbird-fdroid/fdroid/repo

Verify the repository signing fingerprint (SHA-256):

1B 04 9B 81 78 5F 05 09 C1 A4 C5 99 DB 6E B8 73 CB 90 2E 49 62 CE 78 52 8C 94 56 0F F9 7C 68 B0

Railbird requires an account and uses hosted services for core features. The app also includes Google Play, Firebase, and Sentry dependencies.

Beta channel

Prerelease builds for early testing. Beta builds are signed with the same key as regular releases, so a beta install upgrades a stable install in place (and a later stable release supersedes the beta).

Add the beta repository to F-Droid
